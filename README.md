# ngnnah.github.io

Personal blog for sharing thoughts, projects, and learnings.

## About This Site

This is a minimalist personal blog built with Jekyll and hosted on GitHub Pages. The design focuses on readability and simplicity, inspired by [sive.rs](https://sive.rs).

## Features

- Clean, minimalist design
- Responsive layout
- "Now" page with updates archive
- Blog section for longer writings

## Local Development

To run this site locally:

1. Clone the repository
2. Install Jekyll and dependencies: `gem install jekyll bundler`
3. Navigate to the repository directory
4. Run `bundle install`
5. Start the local server: `bundle exec jekyll serve`
6. Visit `http://localhost:4000` in your browser
